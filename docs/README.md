## 📖 各篇概要

### 00 - 零基础起步篇
不需要任何机器学习背景的入口：
- **裂缝修补史**：一张"问题→技术→章节"对照表，全书每个名词都对应一条具体的裂缝
- **三幕剧**：规则时代（例外之外还有例外）→ 统计时代（n-gram 语感天花板）→ 机器学习（给例子、调旋钮）
- **最小数学包**：向量、点积、矩阵×向量、概率分布——各一段话 + 一个算例
- **神经网络 10 分钟**：神经元 → 层 → 参数量 → 多模态（图片怎么变成"词"）
- **一个张量的一生**：1794×1578 截图到输出文字的 13 步形状变化，每步标注源文件与函数
- **环境搭建**：三步跑通第一条 OCR 命令（四个模型各一行命令）

### 01 - Transformer 基础篇
理解 Transformer 的每一个核心组件，以及它为什么长成这样：
- **RNN→Transformer 思想史**：RNN 的"剧情梗概"读法、三大死因（长程遗忘/无法并行/信息瓶颈）、LSTM 门控续命、"像人 ≠ 有效"方法论
- **读法的更换**：评点派 → 文献互文校勘；n² 账单与全书优化章节的伏笔
- **嵌入层**：token → 向量（查表），"为什么不用字典编号"，BF16 零拷贝，嵌入共享
- **位置编码**：RoPE 旋转编码（钟表指针直觉）、2D 位置编码（视觉）、正弦编码（编码器）
- **自注意力**：QKV 投影（图书馆检索类比）、缩放点积（含 √d 方差推导）、因果掩码
- **多头注意力**：批评流派同读一份文本；MHA → GQA → MQA 的演进
- **前馈网络**：研讨课收集证据、回房写成结论；标准 GELU FFN → SwiGLU
- **归一化与残差**：批注不推翻原文、统一字号行距；RMSNorm、Per-head Q/K Norm、Pre-Norm

### 02 - MoE 混合专家篇
深入 MoE 架构的每一个细节：
- **动机**：稠密模型的困境（GPT-3 全参数全勤）与智库解法（64 专家 + 选题会 + 常驻秘书）
- **路由器**：Gate 线性层 + softmax + top-K 选择
- **专家结构**：独立的 SwiGLU FFN，结构相同参数不同
- **共享专家**：永远激活，处理通用知识
- **精度**：BF16 路由确保与 Python 一致
- **ds-ocr 实例**：64 路由专家(top-6) + 2 共享专家
- **训练机制**：负载均衡辅助损失（f_i 与 P_i 完整推导）、容量因子

### 03 - 推理引擎实战篇
纯 C 推理引擎的实现细节：
- **Safetensors**：mmap 零拷贝加载、多分片支持
- **BF16 精度**：存储减半、on-the-fly 转换、流式 argmax
- **数学内核**：generic → NEON → AVX → BLAS 三级优化
- **KV 缓存**：数据结构、显存公式（2·L·S·n_kv·d_head·b + 本仓库算例）、GQA 对缓存大小的影响、动态扩展
- **Prefill vs Decode**：批量矩阵乘法 vs 矩阵×向量
- **采样**：贪心、温度、重复惩罚、n-gram 阻断
- **线程池**：并行矩阵乘法、多 crop 并行

### 04 - 完整推理流程篇
从输入到输出的全链路解析：
- **ds-ocr**：图像预处理 → SAM ViT → DeepEncoder V2 → Projector → Prefill → Decode → 文字
- **qwen-asr**：Mel 频谱图 → Conv+Transformer → Projector → Prefill → Decode → 文字
- **共性模式**：预处理 → 编码 → 投影 → Prompt → Prefill → Decode → 解码
- **失败模式清单与排查手册**

### 05 - 性能优化实战篇
v0.5→v1.1 的完整优化实录：
- **三大阶段优化**：Encoding 50s→9s（5.5×）、Prefill 30s→0.93s（32×）、Decode 19s→5.1s（3.7×）
- **Profiler 数据分析**与内存带宽瓶颈分析
- **R-SWA**（V3 滑窗注意力）效果
- **r1/r2 实录**：head 并行、线程局部门控、BF16 KV、专家块去拷贝——每个按「问题→测量→方案→回归验证」

### 06 - 视觉编码器篇
图片怎么变成语言模型认识的"词"：
- **patch embedding**：一张图 = 一篇 4096 个"词"的文章；卷积层级与训诂拆字同构
- **SAM 窗口注意力 + rel-pos**：局部精读 + 全局层扫视
- **neck 与 4× 空间下采样**：4096 → 256 token（16× 压缩）
- **CLIP-L 语义精炼**与位置嵌入插值两场事故
- **动态多裁剪**逐步算例、newline/分隔 token、四代视觉侧对比

### 07 - 分词与词表篇
文本怎么切成模型的最小单位：
- **BPE 训练/编码手推**、byte-level BPE"中"字七步旅程

### 08 - 解码策略与后处理篇

- **幻觉**：一般成因（掉书袋先生：有语感没档案）与本引擎的数值性成因，三层防御

## 🧪 工程实践：改代码前后的安全网

本书第 05、14 章的每个优化都经过同一套验证流程，工具已内置：

```bash
bash tools/regress.sh   # 30 组"图片↔正确文本"精度回归（CER 对冻结阈值），红=改坏
                        # 资产构成：仓库根 4 张基础图 + docs/golden/images 4 张 r2 场景图，
                        # × 4 模型 = 30 PASS（2 个模型固有退化组合按 tools/exclude.txt 预期 SKIP）；
                        # 冻结标签在 docs/golden/labels/（30 份），阈值在 tools/thresholds.txt
make coverage-unit      # 单元测试快跑（~1 分钟，23 用例 / ~350 断言）+ 每文件行覆盖
make coverage           # 同上 + 四模型 e2e（插桩下较慢，约 1 小时，覆盖更全）
./ds_ocr ... --profile  # 各阶段耗时（编码/预填充/解码）
```

> 覆盖率现状（2026-10-31）：内核/IO/路由层已用例化（safetensors 61%、tokenizer 58%、neon 45%），
> 模型大文件（SAM/编码器/MoE 解码）依赖 e2e 执行才计入；距全引擎 95% 的缺口清单见 `BLOCKED.md` B9。

- `tools/regress.sh`：黄金图集冻结标签 + CER 阈值；任何数值改动先过这道门
- `tools/thresholds.txt`：冻结的 CER 阈值；`tools/exclude.txt`：模型固有退化输入的排除清单
- 教训见 `BLOCKED.md` / `PROGRESS.md`：哪些优化被打回（如编码侧 fast_expf 禁用）、为什么

只想看懂大模型怎么回事、暂时不碰代码：从 00 篇的"裂缝修补史"读起，重点读 01 篇 §1 的 RNN→Transformer 思想史——全书的思想史叙述与人文类比都集中在这两处，之后按兴趣跳读各章开头的直觉段落。
准备动手跑通和学习实现：从 00 篇完整读起（补齐最小数学包 + 跑通第一条命令），再按 01 → 02 → 03 → 04 顺序阅读，每篇读完后在代码中找到对应的实现。

### 有 Transformer 基础的读者
可以跳过 01，直接从 02 开始（MoE 是现代大模型的关键创新）。

### 想直接看推理流程的读者
直接跳到 04，遇到不理解的组件再回看前面的章节。

### 想修改代码的读者
03 是最重要的——理解了引擎的实现细节，才能安全地修改和优化。
